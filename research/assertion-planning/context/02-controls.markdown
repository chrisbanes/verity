# Synthetic controls and terminology

## Social app controls

### Home screen or tab

The Home label names both the feed destination and a persistent Home tab.

### Selected item

A media list can identify one item as selected while remote or keyboard focus is on a different item. Selection and focus are separate control states.

## Settings controls

### Similar rows

Settings screens can contain similarly named rows. An active row may describe an enabled setting, while focus describes the current keyboard or remote target.

## Android TV controls

### Card focus structure

A focused card container may contain title and year text nodes. Some accessibility trees place focus on the card container or on a sibling focus-indicator node rather than on the text node.
