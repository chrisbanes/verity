# Synthetic application context

## com.example.social (Android mobile)

### Home screen or tab

The feed has a Home destination, and a persistent Home tab can also be displayed.

### Detail page

Opening a feed item shows a detail page with separate title and synopsis fields and a backdrop image. A title field has a displayed value.

### Error banner

Feed and detail screens can show a transient error banner.

### Connection status

The account area displays social sign-in status. Media playback or a detail screen can also display network connection readiness. Both areas may report a status as Ready.

### Active profile

The account area has a profile selector. It can show which profile is selected, and each profile can have a separate activity status.

## com.android.settings (Android mobile)

### Network and internet

The Network & internet screen contains an Internet row with its own connection status, such as Connected or Disconnected. Other settings rows have separate statuses.

### System

The main screen contains Network & internet and System destinations.

## com.apple.Preferences (iOS)

### About title

In Settings, General opens About. The About screen displays Name and Title fields; the synthetic sample data supplies their displayed values.

### iOS About error banner

The com.apple.Preferences About screen can display a transient error banner.

### iOS active profile

The account area has a profile selector. It can display which profile is selected, and each profile can have a separate activity status.

## com.example.tv (Android TV)

### Feed and cards

The feed includes a TV Shows row with media cards. A media card can display separate title and year fields and can receive remote focus.

### TV detail page

Opening a TV Shows card shows a detail page with separate title and synopsis fields and a backdrop image.
